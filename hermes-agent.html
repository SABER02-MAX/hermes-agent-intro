简介

为什么叫「会进化的智能体」？

普通智能体每次会话都会重置，Hermes Agent 则持续积累对你和工作的理解——它与你共同成长，而不是每次重新认识你。

与 Claude Code、OpenAI Codex、OpenClaw 同属自主任务执行智能体品类，但 Hermes 的独特之处在于 「闭环学习」：

它在完成复杂任务后会自动沉淀为技能（Skills），技能在使用过程中自我改进；通过 FTS5 会话搜索与 LLM 摘要，跨会话召回相关上下文。你可以在 5 美元的 VPS、GPU 集群或近乎零成本的 serverless 基础设施上运行它——它不绑定你的笔记本，你可以用手机在 Telegram 上指挥一台云服务器上的它。

Hermes 由 Nous Research 开发——即 Hermes 模型家族背后的团队，代码以 MIT 协议完全开源，官方仓库见 github.com/NousResearch/hermes-agent。

它支持任意模型提供商且无锁定：Nous Portal、OpenRouter（200+ 模型）、Anthropic、OpenAI、DeepSeek、通义千问（DashScope）、Kimi 或你自己的本地端点（Ollama / vLLM / LM Studio），用 hermes model 随时切换，无需改代码。

持久记忆

通过 MEMORY.md / USER.md 跨会话保存你的偏好、项目与所学；会话搜索 + LLM 摘要实现「我记得上次做过什么」。

技能自进化

复杂任务完成后自动沉淀为可复用技能，使用中持续改进；兼容 agentskills.io 开放标准，社区技能即装即用。

随处运行

终端 / 桌面应用 / Telegram 等消息平台 / IDE / API Server，本地、Docker、SSH、云端与 serverless 皆可。

核心特性

不止是聊天，而是一整套自主能力

工具、记忆、自动化与集成协同工作，让 Hermes 成为一个真正能独立完成任务的助手。

40+ 内置工具

终端执行、文件编辑、网页搜索、浏览器自动化、代码执行、图像生成、TTS……按平台精细控制启用范围。

技能系统

按需加载的过程性知识文档，渐进式披露以节省 token；支持 hermes skills 搜索与一键安装社区技能。

任意模型无锁定

Nous Portal 300+ 模型、OpenRouter、Anthropic、OpenAI、DeepSeek、通义千问或本地端点，一条命令切换。

多平台接入

Telegram / Discord / Slack / WhatsApp / Signal / Email / Teams 等，单一 gateway 进程统一承载，语音消息自动转写。

MCP 集成

连接任意 MCP 服务器（GitHub、数据库、内部 API），通过 stdio 或 HTTP 扩展外部工具，无需编写原生工具。

子代理并行

delegate_task 派生上下文隔离的子代理，各自拥有受限工具集与独立终端会话，默认 3 路并行处理工作流。

定时任务

用自然语言或 cron 表达式调度任务，结果投递到任意平台，支持暂停 / 恢复 / 编辑，长期自动运行。

安全机制

文件变更前自动快照 Checkpoint，随时 /rollback 回滚；终端可切换 Docker / SSH 沙箱后端；密钥隔离存储。

安装

两条路径，两分钟内跑起来

推荐在 macOS / Windows 使用桌面安装器（CLI + 桌面应用一步到位）；纯命令行安装同样只需一条命令。

terminal
$ curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
$ source ~/.bashrc    # 或 source ~/.zshrc，重载 shell
安装脚本会在 ~/.hermes/hermes-agent 创建受管理的隔离环境（独立 uv 解释器 + venv），这是唯一受支持的安装方式——请勿使用 pip install hermes-agent。Termux 用户请参阅官方 Termux 指南。
powershell
PS> iex (irm https://hermes-agent.nousresearch.com/install.ps1)
Windows 原生安装支持 PowerShell。若你更习惯 Linux 环境，可先安装 WSL2，再在 WSL2 终端中运行左侧的 Linux 安装命令。
macOS / Windows
# 前往官网下载 Hermes Desktop 安装器
# 一条龙安装：命令行 + 桌面应用
# 官网：https://hermes-agent.nousresearch.com
推荐给 macOS / Windows 新手用户：桌面安装器同时安装命令行与桌面应用，安装完成后即可启动图形界面开始对话。
terminal
$ git clone https://github.com/NousResearch/hermes-agent.git
$ cd hermes-agent
$ uv sync                # 创建开发环境
$ uv run python your_app.py   # 在应用中调用 Hermes
将 Hermes 作为 Python 库嵌入自己的应用：官方不发布 wheel 或源码包，请克隆仓库后用 uv 建立可编辑的开发环境。
快速开始

四条命令，从安装到第一次对话

经验法则：先让一次完整对话跑通，再逐步叠加 gateway、定时任务、语音等高级能力。

01

安装 Hermes Agent

按上方「安装」章节选择你的平台，安装后重载 shell 并验证：hermes 命令可用。

terminal
$ curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
02

配置模型 Provider

最简路径：hermes setup --portal——一个 OAuth 登录同时搞定模型与四项工具（网页搜索 / 图像生成 / TTS / 云端浏览器）。也可以运行 hermes model 交互式选择任意提供商（OpenRouter、Anthropic、DeepSeek、通义千问、本地 Ollama……）。

terminal
$ hermes setup --portal   # 一键配置（Nous Portal）
$ hermes model             # 或手动选择任意 provider

要求：模型上下文窗口至少 64K token；本地模型需设置至少 64K（如 llama.cpp --ctx-size 65536）。密钥与普通配置分开存放：密钥 → ~/.hermes/.env，配置 → ~/.hermes/config.yaml。

03

开始第一次对话

启动经典 CLI 或现代 TUI（推荐），用具体且易验证的问题测试工具调用是否正常。

terminal
$ hermes --tui   # 现代 TUI（推荐）；经典 CLI 直接运行 hermes

# 试试这类问题：
#   「Check my current directory and tell me what looks like the main project file.」
#   「Summarize this repo in 5 bullets and tell me what the main entrypoint is.」

成功的标志：横幅显示你的模型 / provider、Hermes 无错误回复、能使用工具（终端 / 文件读取 / 网页搜索）、对话可持续多轮。多行输入用 Alt+Enter 或 Ctrl+J；想中断过长的任务，直接输入新消息回车即可。

04

验证会话恢复，再叠加能力

确认跨会话记忆正常——这是 Hermes 区别于普通智能体的核心。之后按需添加：机器人（hermes gateway setup）、定时任务（Cron）、语音（/voice）、编辑器集成（hermes acp）、沙箱终端（hermes config set terminal.backend docker）。

terminal
$ hermes --continue   # 恢复最近会话（简写：hermes -c）
$ hermes doctor        # 有问题时先诊断：hermes doctor → hermes model → hermes setup
部署

从本机到云端，随时在线工作

Hermes 不依赖你的笔记本——把它部署到服务器，然后用手机、桌面或消息应用随时与它对话。

消息网关机器人

一键接入 Telegram、Discord、Slack、WhatsApp、Signal、Email、Home Assistant、Teams，单进程统一承载，语音消息自动转写。

terminal
$ hermes gateway setup
$ hermes gateway status

云端 / 服务器

跑在 5 美元的 VPS、GPU 集群或 serverless 基础设施上；闲置时环境休眠、成本近乎为零，随时唤醒。

serverless / VPS
# 远程服务器上运行
$ hermes config set terminal.backend ssh

沙箱终端

出于安全考虑，把 Agent 的终端执行隔离在 Docker 容器或远程服务器中，避免影响宿主环境。

terminal
$ hermes config set terminal.backend docker

API Server

将 Hermes 暴露为兼容 OpenAI 格式的 HTTP 端点，接入 Open WebUI、LobeChat、LibreChat 等任意前端。

~/.hermes/.env
API_SERVER_ENABLED=true
API_SERVER_KEY=change-me
$ hermes gateway   # 启动

定时任务 Cron

用自然语言或 cron 表达式调度长期任务：每日报告、监控、数据抓取。结果可投递到任意平台，支持暂停 / 恢复。

会话内
你: /cron 每天早上9点汇总昨日新闻到 Telegram

备份与迁移

整个 ~/.hermes 目录（配置、密钥、记忆、技能、会话）一键打包，换机 / 迁移零丢失。

terminal
$ hermes backup    # 打包 ~/.hermes 到主目录
$ hermes restore   # 新机器上恢复
